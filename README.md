# NESR3 (NES3)

## Gaming-Focused Web3 Token

NESR3 (NES3) is a BEP-20 digital token designed to support the gaming and Web3 ecosystem through gaming-related utility, digital transactions, rewards, and future in-game applications.

The NES3 token is deployed on BNB Smart Chain. The smart contract source code is verified on BscScan.

The official NESR3 game platform is currently under development.
