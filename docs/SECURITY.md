## Risk

No blockchain project can eliminate all technical, market, operational, or regulatory risks.

Potential risks include:

- Smart contract vulnerabilities
- User wallet security
- Market volatility
- Liquidity risk
- Third-party platform risks
- Development risks
- Regulatory changes

Users are responsible for conducting their own research and protecting their own wallet credentials.

---

## Responsible Disclosure

If a security issue is discovered in the project repository or associated code, it should be reported to the project team through the official communication channel listed in `CONTACT.md`.

Do not publicly disclose sensitive vulnerability details before the project team has had an opportunity to investigate.
