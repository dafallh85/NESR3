# NES3 Token Utility

**Updated:** September 29, 2026

---

## Overview

NES3 is the digital token associated with the NESR3 gaming-focused Web3 ecosystem.

The token is designed to support gaming-related utility and future blockchain-based applications.

---

## Current

The deployed NES3 token provides standard BEP-20 functionality.

Current infrastructure includes:

- Token transfers
- Blockchain-based token ownership
- Wallet compatibility within supported Web3 environments
- Community and ecosystem participation

---
